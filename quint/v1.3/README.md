# v1.3 Quint contracts

The four `spec/*.qnt` model files are copied from their corresponding Quint
source at [kogen-spec commit `2e6667eae0d626a5b894588aa465bab35b999928`](https://github.com/KogenAI/kogen-spec/commit/2e6667eae0d626a5b894588aa465bab35b999928).
Adapters and hand scenarios retain the suite migrations described below:

- `approve`: all Approve events carry `baseTree`; observations use `[tree, context]`.
  `09-baseline-cache` changes only the tree, replaces the red row and then reuses
  the identical tree/context.
- `gate`: default policy `green`; `04-advisory` keeps A2 undemoted and ineligible
  under both policies and fully reverifies it after repair. `06-nonzero-runner-exit`
  blocks landing on a failing runner exit; `07-rerun-clears-suite` recovers after
  a successful new run, including refreshed checks; `08-unavailable-reports`
  classifies empty and malformed reports from an unavailable runner. The model's
  observational regression preserves offers and winner too.
- `recovery`: Put carries work/preserved/preserveOk; observations include those
  fields and cleanupPending. `06-preservation-retry` exercises failure, reapproval
  refusal, terminal retry and idempotence; embedded tests include post-CAS work.
- `session`: optional sharedAffinity and versioned prefix map survive NewRun.
  `07-run-affinity` retains the valid run-scoped policy; `08-cross-session-prefix`
  adds shared affinity, pollution refusal and changed-prompt version allowance.

The approval scenario `13-by-invalid` expects the model's specific
`intent/approval_by_invalid` result. Gate hand observations include the model's
`offers` map; the selector adapter projects retained offers while leaving its
unimplemented ledger and verdict seams explicit.

Run `./quint/v1.3/run.sh` with the local spec's existing Quint installation;
`KOGEN_SPEC` can override its location. Goldens are generated by Quint's
invariant-checked transitions, never by an implementation. This projection
contains 40 hand scenarios and five embedded regressions. The external xspec
harness belongs to the spec repository; it is not modified here. At the pinned
models, all 40 hand scenarios, five embedded regressions and 6,000
invariant-checked generated traces passed.

The Elixir adapter wire projections have been migrated. Missing implementation
seams stay explicit (`no_seam`/`not_replayed`); they do not echo the model to fake
conformance. Production adapters live in the implementation repository. The v1.2
`kogen-xspec` binary fails all four updated contracts; detailed results are in
`reference/results/v1.3/quint-*.txt`.
Those abstract failures are reported separately from CLI/filesystem results.
